Skuld

A Python library that uses neural networks to compute definite integrals analytically — no quadrature, no mesh, just trained weights and corner sums.

Python ≥ 3.11 MIT-like License v0.4.0 5 Architectures

Two Methods

Lloyd et al. (2020) — Approximate the integrand with a shallow MLP (sigmoid activation), then integrate the network analytically using polylogarithms. The integral becomes a closed-form expression evaluation.

Maître et al. (2022) — Train a network to approximate the antiderivative, then evaluate the integral as an alternating-sign sum over the corners of the unit hypercube. No quadrature mesh is needed.

Five Architectures

The library provides a unified API across MLP, SIREN, WIRE, KAN, and BrokNet (mixture-of-experts), so you can switch architectures without changing your experiment code.

Supported Architectures

Lloyd et al.

MLP

Classic multilayer perceptron with sigmoid activation. Approximates the integrand; integration via polylogarithms.

Maître et al.

SIREN

Sinusoidal representation network. Approximates the antiderivative; evaluated via corner-sum over the unit hypercube.

Maître et al.

WIRE

Wavelet implicit neural representation using complex Gabor/Morlet wavelet activations with Gaussian envelope.

Maître et al.

KAN

Kolmogorov-Arnold Network with learnable B-spline basis functions on each edge. Stable higher-order autograd.

Maître et al.

BrokNet

Mixture-of-experts ensemble. Each SIREN expert is trained exclusively on one parameter set; deterministic routing.

Infrastructure

Data & Scaling

Five sampling strategies (uniform, grid, log, mixed, exponential) with per-dimension mixing. Min-max scaling for the NNI pipeline.

Key Facts

  • Automatic device selection: CUDA, MPS (Apple Silicon), or CPU
  • No quadrature meshes — integration is a corner-sum evaluation
  • Analytic integration via polylogarithms (Lloyd) or corner sums (Maitre)
  • Parametric integrands supported via theta / param_sets
  • All architectures share the same train() / integrate() API
