Skuld: A neural network based numerical integration library

Skuld computes definite integrals of multi-dimensional functions using neural networks. Instead of sampling a quadrature mesh, it either learns the integrand and integrates it analytically, or learns the antiderivative and reads the answer off the corners of a hypercube.

Read the docs → PyPI Source

Two methods

They are independent approaches, not stages of one pipeline. Either can be used on its own; which one suits a problem depends on the integrand.

01

Approximate the integrand Lloyd et al. 2020

Fit a shallow MLP to the integrand itself, then integrate the network analytically using polylogarithms. Evaluation becomes a closed-form expression, which pays off when one integrand is evaluated over many domains or parameter values — training happens once.

02

Approximate the antiderivative Maître et al. 2022

Train a network so its mixed partial derivatives match the integrand, then evaluate the integral as an alternating-sign sum over the corners of the unit hypercube. There is no mesh and no quadrature rule — only 2n evaluations of the trained network.

Quick start

Every integrator in the library shares the same three-step interface, so swapping SIREN for WIRE or KAN does not change the surrounding code. 

from skuld.siren import SirenIntegrator

# An integrand on the unit cube: f(u, *params) -> Tensor of shape [N]
def integrand(u, a, b, m, n):
    ...

integrator = SirenIntegrator(
    n_params=4,
    n_int_vars=3,
    hidden_sizes=[64, 64, 64],
    omega_0=30.0,
)

history, norm_cache = integrator.train(
    integrand_fn=integrand,
    param_sets=[(0, 0, 1, 2), (1, 1, 2, 3)],
    n_epochs=8000,
)

result = integrator.integrate((0, 0, 1, 2), norm_cache=norm_cache)

A full reference for every integrator, including constructor arguments and sampling strategies, is on the documentation page.

Architectures

The antiderivative method is not tied to one network. Skuld implements a range of activations and structures, including a custom mixture-of-experts ensemble and a purely convolutional variant.

Not every architecture is equally good at this task. Measured accuracy on a particle-physics integrand and on the Genz test functions is reported in the research notes and in the repository.
