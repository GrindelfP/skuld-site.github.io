Documentation

Complete API reference for the Skuld library.

Installation

pip install -e skuld-lib/

Dependencies: torch, numpy, mpmath, scikit-learn. Python ≥ 3.11 required.

Device Selection

Device is selected automatically: CUDA if available, else MPS (Apple Silicon), else CPU. Override with:

from skuld import set_global_device
set_global_device("cpu")   # or "cuda" or "mps"

Data Generation

Five sampling strategies for generating training data:

TypeDescriptionn_samples meaning
"std"Uniform random (Monte-Carlo)Total rows
"grd"Uniform deterministic gridPoints per axis
"log"Logarithmically-spaced gridPoints per axis
"mix"Dense-near-lower + sparse-near-upperPoints per axis
"exp"Exponentially-biased randomTotal rows

Strategies can be mixed per-dimension by passing a list:

from skuld import generate_data

X, y = generate_data(
    dis_type=["std", "std", "exp", "grd"],
    func=my_integrand,
    lower=[0.0, 0.0, 0.0, 0.1],
    upper=[1.0, 1.0, 50.0, 2.0],
    n_samples=200,
    n_dim=4,
)

Scaling

Min-max scaling to a known range (default [0, 1]):

from skuld import scale_data, descale_result

X_scaled, y_scaled = scale_data(X, y, frange=(0, 1))
# ... train and integrate ...
result = descale_result(nni_scaled, X, y, frange=(0, 1), n_dim=4, n_int_dims=3)

MLP — Lloyd et al. Method

This method approximates the integrand itself with a shallow multilayer perceptron (sigmoid activation). Once trained, the network is integrated analytically using polylogarithms — the integral becomes a closed-form expression evaluation rather than a numerical quadrature. This is particularly efficient when the same integrand must be evaluated over many different domains or parameter values, as the expensive training is done once and the evaluation is fast.

from skuld import (generate_data, scale_data, split_data,
                    init_model, NeuralNumericalIntegration, descale_result)

# 1. Generate data
X, y = generate_data("std", func, lower, upper, n_samples=1000, n_dim=3)

# 2. Scale
X, y = scale_data(X, y, frange=(0, 1))

# 3. Split
X_train, X_test, y_train, y_test = split_data(X, y, test_size=0.1, shuffle=True)

# 4. Create model
model = init_model(input_size=3, hidden_size=64)

# 5. Compile
model.compile(criterion=torch.nn.MSELoss(), optimizer_name="adam", learning_rate=1e-3)

# 6. Train
model.fit(X_train, y_train, epochs=5000)

# 7. Integrate analytically
result = NeuralNumericalIntegration.integrate(
    model, alphas=[0,0,0], betas=[1,1,1], n_dims=3, theta=[0.5]
)

# 8. Descale
true_result = descale_result(result, X_init, y_init, frange=(0,1), n_dim=3)

Supported optimizers: adam, adamw, sgd, rmsprop, lbfgs.

SIREN — Maître et al. Method

This method takes a fundamentally different approach: instead of approximating the integrand, a SIREN (Sinusoidal Representation Network) is trained to approximate the antiderivative of the integrand. The network learns a function whose mixed partial derivatives match the integrand. Once trained, the integral is evaluated as an alternating-sign sum over the corners of the unit hypercube — no quadrature mesh is needed. The sinusoidal activation functions are particularly well-suited for this task because they can represent smooth, oscillatory functions and their derivatives are easy to compute via autograd.

from skuld.siren import SirenIntegrator

integrator = SirenIntegrator(
    n_params=4,          # number of fixed parameters
    n_int_vars=3,        # number of integration variables
    hidden_sizes=[64, 64, 64],
    omega_0=30.0,
    output_scale=1.0,
)

history, norm_cache = integrator.train(
    integrand_fn=integrand_fn,       # f(u, *params) -> torch.Tensor
    param_sets=[(0,0,1,2), (1,1,2,3)],
    n_epochs=8000,
    n_per_param=1024,
    lr=5e-4,
)

result = integrator.integrate((0, 0, 1, 2), norm_cache=norm_cache)

WIRE

Wavelet Implicit Neural Representation using complex Gabor/Morlet wavelet activations.

from skuld.wire import WireIntegrator

integrator = WireIntegrator(
    n_params=4,
    n_int_vars=3,
    entry_width=64,
    n_blocks=3,
    omega_0=10.0,
    sigma_0=10.0,
    output_scale=1.0,
)

history, norm_cache = integrator.train(
    integrand_fn=integrand_fn,
    param_sets=[(0,0,1,2), (1,1,2,3)],
    n_epochs=8000,
)

result = integrator.integrate((0, 0, 1, 2), norm_cache=norm_cache)

KAN

Kolmogorov-Arnold Network with learnable B-spline basis functions on each edge.

from skuld.kan import KANIntegrator

integrator = KANIntegrator(
    n_params=4,
    n_int_vars=3,
    width=32,
    depth=2,
    G=8,          # B-spline intervals
    k=3,          # B-spline degree (cubic)
    output_scale=1.0,
)

history, norm_cache = integrator.train(
    integrand_fn=integrand_fn,
    param_sets=[(0,0,1,2), (1,1,2,3)],
    n_epochs=8000,
)

result = integrator.integrate((0, 0, 1, 2), norm_cache=norm_cache)

BrokNet

Mixture-of-experts ensemble. Each SIREN expert is trained exclusively on one parameter set; deterministic routing via dict.

from skuld.broknet import BrokNetIntegrator

integrator = BrokNetIntegrator(
    param_sets=[(0,0,1,2), (1,1,2,3)],  # one expert per set
    n_int_vars=3,
    hidden_sizes=[64, 128, 64],
    omega_0=30.0,
    output_scale=1.0,
)

history, norm_cache = integrator.train(
    integrand_fn=integrand_fn,
    n_epochs=8000,
    n_per_expert=1024,
)

result = integrator.integrate(0, 0, 1, 2, norm_cache=norm_cache)

Common Integrator API

All Maître et al. method integrators share the same interface:

MethodDescription
train(integrand_fn, param_sets, ...)Train the network. Returns (history, norm_cache).
integrate(params, norm_cache)Evaluate integral via corner sum. Returns float.
n_weightsNumber of trainable parameters (property).

The integrand_fn signature is always f(u: torch.Tensor, *params) -> torch.Tensor where u has shape (N, n_int_vars).
