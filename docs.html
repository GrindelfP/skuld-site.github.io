Documentation

A reference for the library's two pipelines and the utilities they share. Every integrator answers the same three questions: what it is called, how it is constructed, and what train() returns.

Installation

From PyPI:

pip install skuld-lib

Or from a checkout of the repository:

pip install -e skuld-lib/

Requires Python 3.11 or newer. Dependencies are torch, numpy, mpmath and scikit-learn.

Integrand approximation

This pipeline fits a network to the integrand and then integrates that network in closed form, using polylogarithms. The expensive step — training — is paid once per integrand; every subsequent evaluation is an expression. That makes it a good fit when one integrand is to be integrated over many domains or parameter values. 

import torch
from skuld import (
    generate_data, scale_data, split_data, init_model,
    NeuralNumericalIntegration, descale_result,
)

# 1. Sample the integrand over the domain of interest.
X, y = generate_data(
    dis_type="std",
    func=integrand,
    lower=[0.0, 0.0, 0.0],
    upper=[1.0, 1.0, 1.0],
    n_samples=1000,
    n_dim=3,
)

# 2. Normalise inputs and outputs.
X_scaled, y_scaled = scale_data(X, y, frange=(0, 1))

# 3. Hold out a test split.
X_train, X_test, y_train, y_test = split_data(
    X_scaled, y_scaled, test_size=0.1, shuffle=True,
)

# 4. Build and configure the network.
model = init_model(input_size=3, hidden_size=64)
model.compile(
    criterion=torch.nn.MSELoss(),
    optimizer_name="adam",
    learning_rate=1e-3,
)

# 5. Train on the scaled data.
model.fit(X_train, y_train, epochs=5000)

# 6. Integrate analytically, mapping the network back to real coordinates.
result = NeuralNumericalIntegration.integrate(
    model, alphas=[0, 0, 0], betas=[1, 1, 1], n_dims=3,
)

# 7. Undo the scaling.
result = descale_result(result, X, y, frange=(0, 1), n_dim=3)
model.compile(optimizer_name=...) One of adam, adamw, sgd, rmsprop or lbfgs.
descale_result(..., n_int_dims=...) Number of integration variables. Must match the value passed to integrate(), or the scaling is undone over the wrong axes.

Antiderivative approximation

This pipeline takes the opposite approach. A network is trained so that its mixed partial derivatives match the integrand, and the integral is then read off as an alternating-sign sum over the 2n corners of the unit hypercube. There is no mesh to build, no quadrature rule to choose, and no closed form to derive — training is the whole cost, and evaluation is a handful of forward passes.

The three steps are always the same, whatever the network:

  1. Write the integrand on the unit cube as f(u, *params).
  2. Construct an integrator and call train().
  3. Call integrate() with a parameter set and the cache that train() returned.
from skuld.siren import SirenIntegrator

def integrand(u, a, b, m, n):
    # u has shape [N, n_int_vars]; the return must also have shape [N].
    ...

integrator = SirenIntegrator(
    n_params=4,
    n_int_vars=3,
    hidden_sizes=[64, 64, 64],
    omega_0=30.0,
    output_scale=1.0,
)

history, norm_cache = integrator.train(
    integrand_fn=integrand,
    param_sets=[(0, 0, 1, 2), (1, 1, 2, 3)],
    n_epochs=8000,
    n_per_param=1024,
    lr=5e-4,
)

result = integrator.integrate((0, 0, 1, 2), norm_cache=norm_cache)

BrokNet

BrokNet is a mixture of experts rather than a single network: each parameter set gets its own SIREN expert, and routing is a lookup rather than a learned gate. Because the expert count is fixed by param_sets, construction differs slightly from the other integrators. 

from skuld.broknet import BrokNetIntegrator

integrator = BrokNetIntegrator(
    param_sets=[(0, 0, 1, 2), (1, 1, 2, 3)],
    n_int_vars=3,
    hidden_sizes=[64, 128, 64],
    omega_0=30.0,
)

history, norm_cache = integrator.train(
    integrand_fn=integrand,
    n_epochs=8000,
    n_per_expert=1024,
)

result = integrator.integrate(0, 0, 1, 2, norm_cache=norm_cache)

AenTrop (tropical max-plus)

AenTrop uses a piecewise-linear convex antiderivative built from the maximum of affine functions, smoothed with log-sum-exp. The temperature tau is annealed from tau_start to tau_end during training. The loss is computed directly on the corner-sum estimate, avoiding the train/eval mismatch of mixed-partial training. 

from skuld.aentrop import AenTropIntegrator

def integrand(u, a, b, m, n):
    # u has shape [N, n_int_vars]; return shape [N]
    ...

integrator = AenTropIntegrator(
    n_params=4,
    n_int_vars=3,
    n_pieces=12,
    tau_start=1.0,
    tau_end=0.01,
)

history = integrator.train(
    integrand_fn=integrand,
    param_sets=[(0, 0, 1, 2), (1, 1, 2, 3)],
    targets={(0, 0, 1, 2): 1.0243, (1, 1, 2, 3): 0.0961},  # exact integrals
    n_epochs=16000,
    lr=1e-3,
)

result = integrator.integrate((0, 0, 1, 2), tau=0.01)

Data generation

generate_data samples a function on a box. The meaning of n_samples depends on the strategy: grid-based strategies produce a Cartesian product with n_samplesn_dim rows, whereas the stochastic ones produce exactly n_samples rows.

Sampling strategies
TypeBehaviourRow count
"std"Uniform random (Monte Carlo)n_samples
"exp"Exponentially biased randomn_samples
"grd"Uniform deterministic gridn_samplesn_dim
"log"Logarithmically spaced gridn_samplesn_dim
"mix"Dense near the lower bound, sparse near the uppern_samplesn_dim

Strategies can be mixed per dimension by passing a list, which is how integrands with a preferred logarithmic direction are usually set up: 

X, y = generate_data(
    dis_type=["std", "std", "exp", "grd"],
    func=integrand,
    lower=[0.0, 0.0, 0.0, 0.1],
    upper=[1.0, 1.0, 50.0, 2.0],
    n_samples=200,
    n_dim=4,
)

Scaling

Neural integrators train far more reliably on normalised inputs and outputs. scale_data applies a min–max map into frange; descale_result inverts it once the integral has been computed. 

from skuld import scale_data, descale_result

X_scaled, y_scaled = scale_data(X, y, frange=(0, 1))

# ... train and integrate in scaled coordinates ...

result = descale_result(
    result_scaled, X, y, frange=(0, 1), n_dim=4, n_int_dims=3,
)

Device selection

The device is chosen automatically: CUDA when present, otherwise MPS on Apple Silicon, otherwise CPU. Override it globally when a run needs a fixed device. 

from skuld import set_global_device

set_global_device("cpu")   # or "cuda" or "mps"

Individual calls also accept a device argument, which takes precedence over the global setting.

Caveats

Three behaviours of the current implementation are easy to trip over, and none of them raise.

Integrands must return shape [N], not [N, 1].

The loss compares a mixed partial of shape [N] against the integrand. An extra trailing dimension broadcasts the mean-squared error to [N, N], so the loss is quietly wrong and training appears to proceed normally.

n_int_vars above 3 gives wrong answers, silently.

Every integrator trains against a mixed partial that is hardcoded to integration variables 0, 1 and 2, while integrate() honours n_int_vars correctly. At six variables the loss decreases happily and the corner sum is then read off a network trained on the wrong derivative.

SechirenIntegrator.train() returns three values.

It returns (history, norm_cache, epoch_data), where epoch_data holds per-epoch timing. Every other integrator returns two. Callers that assume a fixed arity will fail on one class and work on the rest.

AenTropIntegrator.train() requires a targets dict.

Because AenTrop trains directly on the corner-sum loss, it needs the exact integral values for each parameter set during training. Pass them as targets={param_tuple: exact_value}. This differs from all other integrators, which only need the integrand function.
